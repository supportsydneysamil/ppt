# 찬양·성경 제목 슬라이드 테마 설계

## 목표

찬양 슬라이드와 성경 말씀 슬라이드에서 「맨 앞에 제목 슬라이드 추가」를 켰을 때, 그 제목 슬라이드 테마를 고를 수 있게 한다. 지금 쓰는 오리지널 디자인은 기본값으로 유지하고, Custom 타이틀과 같은 네 테마를 추가로 제공한다.

## 범위

포함:

- 찬양 제목 슬라이드
- 성경 말씀 제목 슬라이드와 성경 봉독 제목 슬라이드
- 해당 미리보기, 저장, 템플릿, 개별·묶음 PPTX

제외:

- 주일예배 타이틀 슬라이드 타입 (`title`)
- Custom 타이틀 슬라이드 타입 (`custom-title`)의 기존 동작 변경
- 성경 본문 슬라이드 테마 (`themeId`)와 사용자 배경 이미지
- 메인 화면의 독립 성경 추출 폼(슬라이드 목록이 아닌 TXT/PPTX 다운로드). 이 폼의 제목 슬라이드는 오리지널로 둔다.
- 성경 웹 뷰 화면의 제목 처리

## 데이터 모델

- 필드명: `titleThemeId`
- 허용 값: `original`, `aurora`, `monolith`, `ivory`, `marquee`
- 기본값: `original`
- `normalizeTitleThemeId(value)`는 허용 값이 아니면 `original`을 반환한다.
- 기존 저장본·템플릿에 필드가 없으면 `original`이다.
- `themeId`(성경 본문)와 `titleDesign`(주일예배 타이틀)과 `customTitleDesign`(Custom 타이틀)과 섞지 않는다.
- `includeTitle`이 false이면 `titleThemeId`가 있어도 제목 슬라이드를 넣지 않는다.
- 슬라이드 저장, 템플릿 저장·복제, 성경 재생성 시그니처, 개별 다운로드, 통합 PPTX에서 필드를 보존한다.

성경 시그니처(`buildScriptureSignature`)에 `titleThemeId`를 넣는다. 제목 테마만 바꿔도 시그니처가 달라져 다시 생성한다.

## UI

「맨 앞에 제목 슬라이드 추가」가 켜져 있을 때만 디자인 카드를 보여 준다.

- 찬양: 제목 필드 패널 안에 Custom 타이틀과 같은 `theme-option-grid`를 둔다.
- 성경: 말씀/봉독 라디오 아래에 같은 그리드를 둔다.

카드 순서와 이름은 Custom 타이틀과 맞춘다. 맨 앞에만 오리지널을 둔다.

| ID | 카드 이름 | 설명 |
|---|---|---|
| `original` | 오리지널 | 지금 배경 이미지와 엇갈린 한글 |
| `aurora` | 오로라 그라디언트 | 바이올렛 · 틸 번짐 |
| `monolith` | 모노리스 | 딥 블랙 · 명조 대제목 |
| `ivory` | 아이보리 클래식 | 아이보리 · 이중 금테 |
| `marquee` | 마키 프레임 | 버건디 · 금색 다이아 |

카드 미리보기 스타일은 Custom 타이틀 카드 클래스를 재사용하고, 오리지널 카드만 기존 찬양/말씀 표지 느낌을 보여 준다.

## 렌더 매핑

오리지널은 현재 `addHymnTitleSlide`, `addScriptureTitleSlide`, `addScriptureBongdokTitleSlide`와 기존 찬양 미리보기를 그대로 사용한다.

추가 네 테마는 Custom 타이틀과 같은 배경·프레임·색·부제 헤일로를 쓰고, 글만 아래처럼 넣는다.

| 자리 | 찬양 | 성경 말씀 | 성경 봉독 |
|---|---|---|---|
| 큰 한글 | 찬송 | 성경말씀 | 성경봉독 |
| 영어 줄 | HYMN | SCRIPTURES | SCRIPTURE READING |
| 아래 보조 줄 | 장수가 있으면 `1. 한글제목`, 영어 제목이 있으면 다음 줄 `(English)` | 지금 오리지널 하단과 같은 구절 참조 | 같음 |

보조 줄은 Custom 부제와 같은 영역(`x: 1.07`, `y: 6.1`, `w: 11.19`, `h: 0.85`)과 글자 크기 단계(기본 28pt, 17~24자 24pt, 25자 이상 22pt)와 테마별 헤일로를 사용한다. 보조 줄이 비면 헤일로와 텍스트를 그리지 않고 제목 스택을 중앙에 둔다.

큰 한글과 영어 줄의 글꼴·크기·간격은 Custom 타이틀의 해당 테마 규칙을 따른다. 구분선은 영어 줄이 있을 때만 그린다.

## PPTX와 미리보기

- 새 모듈 `lib/cover-title-slide.js`가 `titleThemeId` 정규화와 추가 네 테마 렌더를 담당한다. 오로라·모노리스·아이보리·마키의 배경·프레임·색·헤일로는 Custom 타이틀 모듈에서 공유하거나 그 모듈이 이미 쓰는 값을 가져와, 팔레트가 서로 어긋나지 않게 한다. 글 배치만 커버 모듈이 담당한다.
- 오리지널 렌더 함수는 옮기지 않는다. `titleThemeId === "original"`일 때만 기존 함수를 호출한다.
- 서버는 찬양 묶음 export의 제목 버퍼와 성경 `buildPptx`의 제목 분기에서 `titleThemeId`를 읽는다.
- 찬양 미리보기는 선택한 테마의 제목 슬라이드를 앞에 붙인다. 오리지널은 지금 DOM 미리보기, 추가 테마는 Custom 타이틀 미리보기와 같은 좌표 규칙을 쓴다.
- 성경 제목은 생성 결과 PPTX에 포함되므로, 테마 변경 후 다시 생성해야 미리보기가 바뀐다.

## 실패 처리

- 알 수 없는 `titleThemeId`는 `original`이다. 요청을 거절하지 않는다.
- `includeTitle`이 꺼져 있으면 제목 슬라이드를 넣지 않는다.
- 성경 본문 `themeId`와 사용자 배경 이미지는 제목 테마에 영향을 주지 않는다.
- 찬양 한글·영어 제목이 비어 있으면 보조 줄에 있는 값만 그린다. 둘 다 없고 장수도 없으면 보조 줄을 생략한다.

## 검증

- `normalizeTitleThemeId`와 찬양/말씀/봉독 텍스트 매핑 단위 테스트
- 슬라이드 레코드·템플릿 직렬화에서 `titleThemeId` 보존과 기본값 `original`
- 성경 시그니처에 `titleThemeId`가 들어가 테마만 달라도 재생성이 필요한지
- 찬양·말씀·봉독 export에서 오리지널과 `aurora`가 제목 슬라이드를 앞에 붙이는지
- 추가 테마 PPTX가 Custom 타이틀과 같은 테마 색·부제 영역을 쓰는지
- 기존 제목 슬라이드를 끈 찬양/말씀과 주일예배·Custom 타이틀 동작이 그대로인지
