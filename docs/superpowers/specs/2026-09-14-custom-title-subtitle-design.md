# Custom 타이틀 부제 설계

## 목표

`타이틀 (Custom)` 슬라이드에 선택 입력인 부제 필드를 추가한다. 부제는 제목 묶음과 분리된 하단 소프트 헤일로 영역에 표시되며, 편집 중 미리보기와 생성된 PPTX가 같은 위치와 스타일을 사용해야 한다.

## 데이터 모델

- 필드명: `customTitleSubtitle`
- 기본값: 빈 문자열
- 앞뒤 공백을 제거한 값으로 편집 초안과 저장 데이터를 구성한다.
- 슬라이드 저장, 템플릿 저장·복제, 개별 다운로드, 통합 PPTX 생성 과정에서 필드를 보존한다.
- 빈 값이면 기존 Custom 타이틀의 출력과 레이아웃을 변경하지 않는다.

## UI와 미리보기

- `타이틀 이름` 패널에 `부제 (선택)` 텍스트 입력을 추가한다.
- 입력할 때 미리보기와 저장 상태를 즉시 갱신한다.
- 제목 묶음을 기존 중앙 위치보다 0.45인치 위로 이동한다.
- 부제 영역은 슬라이드 하단에서 0.55인치 떨어진 위치에 0.85인치 높이로 배치한다.
- 부제는 기본 28pt Bold 고딕체로 한 줄 표시한다. 공백을 제외한 글자 수가 17~24자이면 24pt, 25자 이상이면 22pt로 축소한다.
- 부제 뒤에는 테두리, 직사각형 색면, 선, 점, 다이아몬드, 기타 심볼을 표시하지 않는다.
- 부제 중앙 뒤에만 가장자리로 갈수록 완전히 투명해지는 넓은 타원형 방사형 빛을 표시한다.
- 네 디자인은 같은 부제 영역을 사용하되 기존 테마의 포인트 색을 낮은 농도로 적용한다. 백분율은 그라디언트 중심점의 불투명도이며 가장자리에서는 0%가 된다.
  - 오로라: 바이올렛 `C4B2FF` 15% 빛과 `FFFFFF` 부제
  - 모노리스: 흰색 `FFFFFF` 10% 빛과 `EEE9DC` 부제
  - 아이보리: 웜 골드 `C2A87A` 16% 빛과 `5F4B2C` 부제
  - 마키: 골드 `D9B376` 12% 빛과 `F7EBDA` 부제

## PPTX 렌더링

- 네 디자인 모두 기존 제목 스택을 재사용하되 부제가 있으면 스택 전체를 0.45인치 위로 이동한다.
- 부제는 제목 스택에 포함하지 않고 독립적인 하단 영역으로 렌더링한다.
- PPTX에서는 투명 방사형 그라디언트 SVG 이미지를 부제 뒤에 배치하고, 미리보기에서는 같은 색상과 농도의 CSS `radial-gradient`를 사용한다.
- 빛 이미지와 부제 텍스트는 `x: 1.07`, `y: 6.1`, `w: 11.19`, `h: 0.85`인 동일 영역을 사용한다.
- 영문 제목이 있을 때만 기존 구분선을 렌더링한다.
- 빈 부제이면 빛과 부제 텍스트를 렌더링하지 않고 기존 제목 스택의 중앙 위치를 유지한다.
- 미리보기와 PPTX는 동일한 부제 크기 단계, 영역 비율, 테마 색상과 빛 농도를 사용한다.

## 검증

- 직렬화 테스트에서 `customTitleSubtitle` 보존과 빈 문자열 기본값을 확인한다.
- PPTX 렌더링 테스트에서 부제 텍스트, 하단 빛 이미지 위치, 글자 크기 단계가 생성된 슬라이드 XML에 반영되는지 확인한다.
- 네 테마 모두 기존 패널과 장식 도형이 사라지고 테마별 헤일로 이미지 하나만 생성되는지 확인한다.
- 전체 테스트와 프런트엔드 빌드를 실행해 기존 슬라이드 동작의 회귀 여부를 확인한다.
