# Custom 타이틀 부제 설계

## 목표

`타이틀 (Custom)` 슬라이드에 선택 입력인 부제 필드를 추가한다. 부제는 제목 묶음과 분리된 하단 시그니처 패널에 표시되며, 편집 중 미리보기와 생성된 PPTX가 같은 위치와 스타일을 사용해야 한다.

## 데이터 모델

- 필드명: `customTitleSubtitle`
- 기본값: 빈 문자열
- 공백을 제거한 값으로 편집 초안과 저장 데이터를 구성한다.
- 슬라이드 저장, 템플릿 저장·복제, 개별 다운로드, 통합 PPTX 생성 과정에서 필드를 보존한다.
- 빈 값이면 기존 Custom 타이틀의 출력과 레이아웃을 변경하지 않는다.

## UI와 미리보기

- `타이틀 이름` 패널에 `부제 (선택)` 텍스트 입력을 추가한다.
- 입력할 때 미리보기와 저장 상태를 즉시 갱신한다.
- 제목 묶음을 기존 중앙 위치보다 0.45인치 위로 이동한다.
- 부제 패널은 슬라이드 하단에서 0.55인치 떨어진 위치에 0.85인치 높이로 배치한다.
- 부제는 기본 28pt Bold 고딕체로 한 줄 표시한다. 공백을 제외한 글자 수가 17~24자이면 24pt, 25자 이상이면 22pt로 축소한다.
- 패널 외곽선은 표시하지 않고 색면과 최소한의 테마 포인트만 사용한다.
- 네 디자인은 같은 패널 위치를 사용하되 기존 테마에 맞는 표현을 적용한다.
  - 오로라: 반투명 딥 바이올렛 색면
  - 모노리스: 무광 블랙 색면과 짧은 중앙 포인트 선
  - 아이보리: 옅은 아이보리 색면과 양끝의 작은 골드 포인트
  - 마키: 버건디 색면과 양끝의 작은 골드 다이아

## PPTX 렌더링

- 네 디자인 모두 기존 제목 스택을 재사용하되 부제가 있으면 스택 전체를 0.45인치 위로 이동한다.
- 부제는 제목 스택에 포함하지 않고 독립적인 하단 패널로 렌더링한다.
- 패널 도형의 외곽선은 완전히 투명하게 렌더링한다.
- 영문 제목이 있을 때만 기존 구분선을 렌더링한다.
- 빈 부제이면 패널을 렌더링하지 않고 기존 제목 스택의 중앙 위치를 유지한다.
- 미리보기와 PPTX는 동일한 부제 크기 단계, 패널 비율, 테마 색상을 사용한다.

## 검증

- 직렬화 테스트에서 `customTitleSubtitle` 보존과 빈 문자열 기본값을 확인한다.
- PPTX 렌더링 테스트에서 부제 텍스트, 하단 패널 위치, 글자 크기 단계가 생성된 슬라이드 XML에 반영되는지 확인한다.
- 전체 테스트와 프런트엔드 빌드를 실행해 기존 슬라이드 동작의 회귀 여부를 확인한다.
