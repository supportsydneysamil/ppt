# Custom 타이틀 부제 설계

## 목표

`타이틀 (Custom)` 슬라이드에 선택 입력인 부제 필드를 추가한다. 부제는 영문 제목 아래에 표시되며, 편집 중 미리보기와 생성된 PPTX가 같은 순서와 스타일을 사용해야 한다.

## 데이터 모델

- 필드명: `customTitleSubtitle`
- 기본값: 빈 문자열
- 공백을 제거한 값으로 편집 초안과 저장 데이터를 구성한다.
- 슬라이드 저장, 템플릿 저장·복제, 개별 다운로드, 통합 PPTX 생성 과정에서 필드를 보존한다.
- 빈 값이면 기존 Custom 타이틀의 출력과 레이아웃을 변경하지 않는다.

## UI와 미리보기

- `타이틀 이름` 패널에 `부제 (선택)` 텍스트 입력을 추가한다.
- 입력할 때 미리보기와 저장 상태를 즉시 갱신한다.
- 기존 한글 제목과 영문 제목 다음에 부제를 배치한다.
- 영문 제목이 비어 있으면 구분선 없이 한글 제목 다음에 부제를 배치한다.
- 부제는 작은 고딕체와 각 디자인의 보조색을 사용한다.

## PPTX 렌더링

- 네 디자인 모두 기존 중앙 스택 레이아웃을 재사용한다.
- 부제가 있으면 마지막 스택 블록으로 추가하여 전체 제목 묶음이 중앙 정렬되게 한다.
- 영문 제목이 있을 때만 기존 구분선을 렌더링한다.
- 부제의 높이와 위쪽 간격은 고정해 미리보기와 PPTX에서 동일한 비율을 유지한다.

## 검증

- 직렬화 테스트에서 `customTitleSubtitle` 보존과 빈 문자열 기본값을 확인한다.
- PPTX 렌더링 테스트에서 부제 텍스트가 생성된 슬라이드 XML에 포함되는지 확인한다.
- 전체 테스트와 프런트엔드 빌드를 실행해 기존 슬라이드 동작의 회귀 여부를 확인한다.
