# 슬라이드 편집 취소·초기화 UX 설계

## 목표

슬라이드 편집기의 `취소`와 `슬라이드 초기화`를 서로 다른 범위의 작업으로 구분한다. 두 작업 모두 현재 슬라이드 선택과 편집 맥락을 유지한다.

## 취소

- 마지막 저장 상태로 현재 슬라이드의 편집 초안만 복구한다.
- 현재 슬라이드 ID, 목록 위치, 활성 카드와 편집기 표시 상태를 유지한다.
- 템플릿 이름·순서 등 슬라이드 밖의 변경사항에는 영향을 주지 않는다.
- 변경사항이 없으면 비활성화한다.
- 새 슬라이드에서는 현재 초안을 제거하고 가장 가까운 인접 슬라이드를 선택한다. 인접 슬라이드가 없으면 빈 상태를 표시한다.

## 슬라이드 초기화

- 버튼 문구를 `리셋`에서 `슬라이드 초기화`로 변경한다.
- 슬라이드 ID, 목록 위치, 타입과 이름은 유지한다.
- 선택한 타입이 사용하는 콘텐츠, 디자인 설정, 첨부파일을 타입별 초기값으로 바꾼다.
- 초기화는 저장본을 즉시 덮어쓰지 않고 미저장 초안을 만든다. 사용자가 `저장`해야 서버 또는 템플릿에 반영된다.
- 커스텀 슬라이드는 빈 흰색 캔버스로 초기화한다.
- 초기화 결과가 현재 초안과 같으면 버튼을 비활성화한다.
- 단, 저장본 자체가 해당 타입의 초기값이고 편집 중인 초안을 그 상태로 되돌린 경우에는 새 미저장 변경을 만들지 않는다. 이때 저장과 취소는 비활성화되고 포커스는 활성화된 편집 필드로 이동한다.

## 확인 대화상자

초기화 버튼을 누르면 다음 내용을 표시한다.

- 제목: `슬라이드를 초기화할까요?`
- 설명: `현재 입력한 내용, 디자인과 첨부파일이 이 슬라이드 타입의 초기값으로 변경됩니다. 저장하기 전에는 취소할 수 있습니다.`
- 보조 버튼: `돌아가기`
- 위험 버튼: `초기화`

Escape와 배경 클릭은 `돌아가기`와 동일하다. 확인 후에도 현재 슬라이드는 선택된 상태로 남는다.
커스텀 슬라이드의 비동기 초기화 중에는 대화상자 안에 `초기화하는 중입니다…`를 표시하고 `aria-live="polite"` 상태로 알린다.

## 상태와 복구

- 초기화 후에는 원칙적으로 `slideDirty=true`이고 저장 버튼이 활성화된다. 저장본의 타입별 초기값으로 정확히 복귀한 예외에서는 깨끗한 상태를 유지한다.
- 초기화 후 `취소`를 누르면 마지막 저장 상태가 복원된다.
- 저장 중에는 취소와 초기화를 모두 차단하고 기존 저장 중 안내를 사용한다.
- 일반 슬라이드와 템플릿 작업 공간 모두 같은 슬라이드 범위 규칙을 적용한다.

## 완료 기준

1. 기존 슬라이드의 취소가 저장 상태를 복구하고 선택을 유지한다.
2. 새 슬라이드의 취소가 초안을 제거하고 인접 슬라이드를 선택한다.
3. 초기화가 타입과 이름을 유지하면서 타입별 데이터를 초기값으로 바꾼다.
4. 초기화 확인을 거절하면 아무 상태도 바뀌지 않는다.
5. 커스텀 슬라이드 초기화가 빈 캔버스를 만들고 취소로 저장본을 복원할 수 있다.
