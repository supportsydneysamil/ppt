# 기타 타이틀 디자인 3종 설계

## 목표

주일예배 타이틀 선택기의 `기타` 카테고리에 색상과 구도가 서로 겹치지 않는 고급 디자인 3종을 추가한다. 세 디자인은 긴 제목, 선택적인 부제·영문·날짜에도 균형을 유지하며 PPT 출력과 브라우저 미리보기가 같은 지오메트리를 사용한다.

## 디자인

### 블랙 리저브

- 팔레트: 딥블랙 배경, 웜화이트 제목, 건메탈과 옅은 브론즈 포인트
- 구도: 신규 `gallery-rail`
- 제목 묶음은 광학 중심보다 약간 위에 배치한다.
- 교회명은 상단에 절제해 두고, 날짜는 하단의 짧은 정보 레일에 배치한다.
- 넓은 자간과 최소한의 선만 사용해 장식적인 상자 없이 깊이감을 만든다.

### 코발트 포털

- 팔레트: 코발트 블루 배경, 아이보리 제목, 밝은 블루 포인트
- 구도: 신규 `portal-offset`
- 좌우 폭이 다른 문 형태를 사용하되 제목 묶음의 중심과 시각적 무게는 슬라이드 중앙에 맞춘다.
- 교회명과 날짜는 서로 반대쪽 보조 영역에 배치해 비대칭 구도의 균형을 맞춘다.

### 테라코타 에디션

- 팔레트: 따뜻한 크림 배경, 테라코타 제목, 브론즈 포인트
- 구도: 신규 `editorial-index`
- 넓은 본문 영역과 좁은 측면 인덱스 영역을 분리한다.
- 제목·부제·영문은 본문 영역에 정렬하고 교회명·날짜는 인덱스 영역에서 수직적으로 균형을 이룬다.

## 구현 경계

- `lib/title-slide-layout.js`에 세 구도의 지오메트리와 콘텐츠 존 배치를 추가한다.
- `lib/title-slide-catalog-render.js`가 신규 장식과 존 텍스트를 PPT에 그린다.
- `public/app.js`가 동일한 공유 지오메트리를 사용해 선택기 미리보기를 그린다.
- `lib/title-slide-design-catalog.js`의 `premium` 목록에 세 디자인을 추가한다.
- 별도 이미지 자산은 추가하지 않는다. 색, 도형, 타이포그래피만 사용한다.

## 검증

- 카탈로그 수, 이름, ID, 구도 매핑을 테스트한다.
- 세 구도의 콘텐츠 스택과 존 배치를 테스트한다.
- PPT XML에서 각 구도의 장식과 텍스트가 생성되는지 확인한다.
- 브라우저 미리보기가 공유 지오메트리와 신규 구도를 처리하는지 확인한다.
- 세 디자인을 실제 PPT와 선택기 미리보기로 렌더링해 기본·긴 제목·최소 콘텐츠 상태를 육안 검토한다.
- 전체 테스트와 프로덕션 빌드를 통과시킨 후 커밋하고 `origin/main`에 푸시한다.
