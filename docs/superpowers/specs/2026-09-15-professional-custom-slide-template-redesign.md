# 프로페셔널 커스텀 슬라이드 템플릿 재설계

## 목표

현재 커스텀 슬라이드 템플릿 15종을 교회 현장에서 바로 사용할 수 있는 수준으로 개선한다. 장식만 바꾸는 것이 아니라 각 슬라이드의 목적, 정보 위계, 시선 흐름, 원거리 가독성, 편집 단위를 기준으로 구조를 다시 설계한다.

## 확정 방향

**목적 중심 프레젠테이션 시스템**을 적용한다.

- 템플릿마다 목적에 맞는 구도와 정보 구조를 사용한다.
- 15종 전체는 공통 그리드, 타입 스케일, 안전 여백, 색 역할로 하나의 제품처럼 통일한다.
- 불필요한 장식은 제거하고 의미가 있는 선, 면, 번호, 프레임만 사용한다.
- 기존 템플릿 ID와 저장 모델 호환성을 유지한다.
- 템플릿의 네이티브 팔레트와 기존 21개 전역 테마를 모두 지원한다.

## 범위

### 포함

- `blank`를 제외한 14개 템플릿의 요소, 좌표, 기본 문구, 네이티브 색 재설계
- `blank`는 요소 없는 자유 제작용 템플릿으로 유지
- 템플릿별 목적에 맞춘 독립 편집 단위 구성
- 모든 색 요소에 의미 기반 `themeRole` / `themeStrokeRole` 적용
- 네이티브, 밝은 전역 테마, 어두운 전역 테마에서의 시각 검수
- 템플릿 구조, 경계, 테마 적용을 검증하는 자동 테스트

### 제외

- 템플릿 ID 추가·삭제 또는 이름 변경
- 저장 모델 스키마 변경
- 커스텀 슬라이드 편집기 동작 변경
- 외부 사진, 아이콘, 일러스트 파일 추가
- 그라데이션·필터·새 Fabric 요소 타입 추가
- 전역 색 테마 목록 변경
- 주일예배 타이틀 카탈로그 변경

## 공통 디자인 시스템

### 캔버스와 그리드

- 캔버스는 기존과 동일한 1280×720, 16:9다.
- 핵심 콘텐츠는 좌우 최소 88px, 상하 최소 56px의 안전 영역 안에 둔다.
- 위치와 간격은 8px 단위를 기본으로 하되 광학 정렬이 필요한 텍스트는 예외를 허용한다.
- 정보형 템플릿은 공통 열 기준을 사용해 제목, 본문, 메타 정보의 시작점을 맞춘다.
- 텍스트 상자는 예상 기본 문구보다 긴 실제 한국어 문장을 수용할 높이와 폭을 가진다.

### 타이포그래피

- 기존 렌더링·PPTX 호환성을 위해 기본 글꼴은 `Malgun Gothic`을 유지한다.
- 한 템플릿에서 제목, 본문, 보조 정보의 최대 3단계 위계만 사용한다.
- 제목은 48–72px, 주요 낭독·가사는 44–56px, 본문은 28–36px, 보조 정보는 18–24px 범위에서 목적에 맞게 정한다.
- 긴 공동 낭독문은 중앙 정렬하지 않고, 좁은 좌측 정렬 열과 충분한 줄 간격을 사용한다.
- 기본 본문의 한 줄 길이는 큰 스크린에서 시작점을 잃지 않도록 제한한다.

### 색과 장식

- 각 템플릿은 `background`, `surface`, `accent`, `title`, `body`, `muted`, `stroke` 역할만으로 구성한다.
- 장식 도형도 의미 있는 역할을 갖고, 전역 테마 적용 시 일관되게 재색상된다.
- 작은 장식 여러 개보다 하나의 강한 기준선, 프레임, 번호 또는 면을 사용한다.
- 불투명도 차이는 허용하지만 테마 팔레트 밖의 고정 색은 사용하지 않는다.
- 사진 템플릿의 기본 상태는 2–3개의 역할 기반 면으로 만든 추상 플레이스홀더를 사용해 사진이 없어도 미완성처럼 보이지 않게 한다.

## 템플릿별 설계

### 1. 빈 슬라이드 (`blank`)

- 현재 구조를 유지한다.
- 요소 없이 선택한 테마의 배경색만 적용한다.
- 자유 제작용 도구이므로 장식이나 안내 문구를 추가하지 않는다.

### 2. 타이틀 히어로 (`title-hero`)

- 기존의 화면 전체 파란 띠를 제거한다.
- 얇은 인셋 프레임, 상단 짧은 강조선, 중앙 제목, 날짜·예배명 메타 정보로 구성한다.
- 일반 예배, 행사, 시리즈의 오프닝 화면으로 사용한다.
- 제목이 가장 강한 단일 초점이 되며 설교 본문·설교자 영역은 두지 않는다.

### 3. 좌우 분할 사진 (`split-photo`)

- 사진/플레이스홀더 영역을 화면 왼쪽 약 44%에 가장자리까지 배치한다.
- 오른쪽은 작은 분류 라벨, 2행 제목, 짧은 본문, 하단 강조선으로 구성한다.
- 기본 추상 플레이스홀더는 사진을 추가하지 않아도 의도된 면 구성처럼 보인다.
- 사진을 추가할 때는 왼쪽 영역을 자연스럽게 덮을 수 있다.

### 4. 인용 카드 (`quote-card`)

- 둥근 카드와 UI형 테두리를 제거한다.
- 큰 반투명 인용 부호, 좁은 인용문 열, 하단 기준선, 우측 출처를 사용한다.
- 말씀, 간증, 저자 인용이 화면의 중심이 되며 장식은 보조 역할만 한다.

### 5. 예배 순서 (`agenda-list`)

- 하나의 번호 목록 텍스트를 번호, 순서명, 담당자 행으로 분리한다.
- 작은 영문 라벨, 제목, 행 구분선, 3개 기본 순서, 하단 교회명을 둔다.
- 한 행은 강조 면을 사용해 현재 순서를 나타낼 수 있다.
- 각 행의 번호·순서명·담당자는 독립 텍스트 요소여서 바로 편집할 수 있다.

### 6. 성경 본문 (`scripture`)

- 기존의 왼쪽 강조선과 본문 중심 개념은 유지한다.
- 왼쪽에 책 이름과 큰 장·절을 묶은 장절 레일을 둔다.
- 세로 구분선 오른쪽에 읽기 폭을 제한한 본문을 배치한다.
- 하단에는 작은 섹션 라벨을 둔다.
- 기본 본문보다 현저히 긴 문장은 글자를 축소하기보다 여러 슬라이드로 나누는 사용을 전제로 한다.

### 7. 찬양 가사 (`lyrics`)

- 중앙의 큰 가사라는 핵심 구조를 유지한다.
- 좌상단에 곡명·절 정보, 우상단에 페이지 번호를 둔다.
- 가사는 중앙 안전 영역에 2–4줄이 들어가도록 넓은 행간을 사용한다.
- 하단에는 하나의 짧은 강조선만 사용한다.

### 8. 설교 제목 (`sermon-title`)

- 타이틀 히어로와 역할이 겹치지 않도록 비대칭 에디토리얼 구도로 전면 재설계한다.
- 왼쪽에는 시리즈 라벨과 2행 제목을 둔다.
- 오른쪽 프레임에는 시리즈 회차, 본문, 설교자를 배치한다.
- 하단 기준선으로 좌우 정보를 하나의 구성으로 묶는다.

### 9. 설교 요점 (`sermon-points`)

- 하나의 번호 목록 텍스트를 3개의 번호와 요점 요소로 분리한다.
- 상단에는 섹션 라벨, 제목을 두고 하단에는 본문 장절을 둔다.
- 세로로 반복되는 번호와 문장 시작점을 맞춰 논리 흐름이 즉시 보이게 한다.
- 긴 한국어 문장에 불리한 3열 카드 구조는 사용하지 않는다.

### 10. 교회 광고 (`announcements`)

- 불릿 문단을 제거하고 3개의 소식 카드로 구성한다.
- 각 카드에는 날짜·주기, 소식 제목, 시간·장소를 독립 요소로 둔다.
- 카드 상단의 굵은 선과 면 색으로 정보를 구분하되 과도한 그림자나 둥근 모서리는 사용하지 않는다.
- 세 소식을 동일한 구조로 빠르게 훑을 수 있어야 한다.

### 11. 공동 고백·기도문 (`creed`)

- 중앙 정렬 긴 문장을 좌측 정렬 낭독 열로 바꾼다.
- 상단 섹션 라벨과 제목, 구분선, 본문, 하단 페이지·낭독자 정보로 구성한다.
- 본문 폭과 줄 간격은 회중이 줄 시작점을 잃지 않는 것을 우선한다.

### 12. 기도 제목 (`prayer`)

- 설교 요점과 동일했던 번호 목록 구조를 분리한다.
- 왼쪽에는 섹션 라벨, 제목, 세 기도 항목을 배치한다.
- 오른쪽에는 화면 밖으로 일부 나가는 큰 원형 선과 세로 보조 문구를 두어 차분한 상징성을 만든다.
- 번호와 기도 제목은 독립 요소로 편집한다.

### 13. 환영 (`welcome`)

- 중앙 인사말 두 줄에서 환대와 행동 안내가 함께 있는 비대칭 구조로 바꾼다.
- 왼쪽에는 환영 라벨, 큰 인사말, 축복 문구를 둔다.
- 오른쪽 정보 면에는 새가족 안내와 위치를 둔다.
- 배경의 큰 원형 선은 따뜻한 분위기를 만들되 텍스트를 침범하지 않는다.

### 14. 봉헌 (`offering`)

- 예배 흐름의 경건한 전환점으로 설계한다.
- 얇은 인셋 프레임, 상단 강조선, 중앙 제목, 짧은 말씀, 장절을 대칭으로 배치한다.
- 아이콘이나 직접적인 화폐 이미지는 사용하지 않는다.

### 15. 다음 주 안내 (`next-week`)

- 왼쪽에 큰 일자와 월·요일을 묶어 날짜를 가장 먼저 보이게 한다.
- 세로 구분선 오른쪽에는 예배명, 시간, 장소를 배치한다.
- 우하단에는 짧은 재방문 메시지 면을 둔다.
- 현재처럼 날짜 영역에 단순히 “주일”만 표시하지 않는다.

## 모델과 호환성

- 기존 `TEMPLATE_DEFINITIONS`, `CUSTOM_SLIDE_TEMPLATES`, `instantiateTemplate` 흐름을 유지한다.
- 템플릿 ID, 라벨, `themeId`, `templateId`, 요소 직렬화 방식은 바꾸지 않는다.
- 모델이 이미 지원하는 `text`, `rect`, `roundRect`, `ellipse`, `line`만 사용한다.
- 각 요소에는 기존 정규화기가 보존하는 `themeRole` 또는 `themeStrokeRole`을 지정한다.
- 사용자가 템플릿을 적용하면 지금처럼 요소 ID가 새로 생성된다.
- 수동 색상 변경 시 테마 역할을 해제하는 기존 동작을 유지한다.

## 테스트와 시각 검수

### 자동 테스트

- 템플릿 ID와 라벨 15개가 그대로 유지되는지 확인한다.
- `blank`만 요소가 없고 나머지 템플릿에는 목적에 필요한 최소 요소가 있는지 확인한다.
- 모든 요소의 x/y/width/height 또는 선 끝점이 1280×720 안에 있거나, 의도적으로 잘린 장식만 허용 목록에 있는지 확인한다.
- 각 비어 있지 않은 템플릿에 `title` 또는 `body` 텍스트 역할과 하나 이상의 구조적 역할이 있는지 확인한다.
- 정보 분리가 중요한 템플릿은 독립 요소 수를 검증한다.
  - `agenda-list`: 번호·순서명·담당자 3행
  - `sermon-points`: 번호·요점 3개
  - `announcements`: 날짜·제목·상세 3개
  - `prayer`: 번호·기도 제목 3개
- 네이티브와 대표 밝은/어두운 테마 적용 후 텍스트, 좌표, 크기가 변하지 않고 색만 바뀌는지 확인한다.
- 기존 커스텀 슬라이드 모델, 컨트롤러, 히스토리 테스트가 모두 통과해야 한다.

### 시각 검수

- 15개 템플릿을 네이티브 팔레트로 한 번씩 실제 캔버스에 렌더링한다.
- 대표 밝은 테마 `plain`과 어두운 테마 `deep-black`을 14개 디자인 템플릿에 적용해 대비와 역할 매핑을 확인한다.
- 16:9 전체 화면에서 좌우 안전 여백, 겹침, 잘림, 지나치게 긴 행, 미완성 플레이스홀더 인상을 확인한다.
- 템플릿별 기본 문구가 편집 전에도 실제 발표 예시처럼 보여야 한다.

## 성공 기준

- 모든 디자인 템플릿이 기존안보다 목적이 분명하고 서로 구별된다.
- 기본 상태가 데모용 와이어프레임이나 편집기 UI처럼 보이지 않는다.
- 사용자는 내용만 바꿔도 발표 가능한 수준의 구도와 정보 위계를 얻는다.
- 템플릿을 수정하지 않고 색 테마만 바꿔도 구성과 가독성이 유지된다.
- 기존 저장 데이터와 편집 동작에 회귀가 없다.
